# Brodansh — جلسات المناديب وشاشة المطبخ

تم ضبط قاعدة بيانات **brodansh** على [https://brodansh.de.com.eg](https://brodansh.de.com.eg) بحيث يكون لكل مندوب نقطة بيع وجلسة مفتوحة، وشاشة مطبخ مستقلة بمراحل الطلب المطلوبة.

## ما الذي تغيّر على برودانش

### مراحل شاشة المطبخ
بدل «للتجهيز / جاهز / مكتمل»:

1. **مؤكد**
2. **تم الشحن**
3. **الفوترة**

اضغط بطاقة الطلب لنقلها للمرحلة التالية. «استرجاع» يعيدها للمرحلة السابقة.

### جلسة لكل مندوب
فُتحت جلسة POS لكل نقطة بيع يبدأ اسمها بـ `مندوب —`:

| نقطة البيع | المستخدم على الجلسة |
| --- | --- |
| مندوب — حسام الدين علي عباس | حسام الدين علي عباس |
| مندوب — عبدالمجيد | عبدالمجيــد 111 |
| مندوب — محمد لطفي | محمد لطفي 11 |
| مندوب — محمد مقبل | محمد مقبل |
| مندوب — محمود صلاح برهومة | محمود صلاح برهومة |
| مندوب — عبدالرحمن لطفي | عبدالرحمن لطفي ( ابو عمر) |
| مندوب — احمد مهران | احمد مهران |
| مندوب — صادق حنفي مهران | صادق حنفي مهران |
| مندوب — محمد صلاح | محمد صلاح |
| مندوب — معاذ خالد | معاذ خاالد |

### الشاشات
- **مناديب**: شاشة مجمّعة لكل المناديب (نقاط الجملة فُصلت عنها).
- **شاشة مندوب — …**: شاشة خاصة بكل مندوب، مربوطة بنقطة بيعه فقط.

افتح الشاشات من: **نقطة البيع → الطلبات → شاشة تحضير الطعام**.

كل مندوب يدخل نقطة البيع الخاصة به من لوحة نقطة البيع ثم يرسل الطلبات لتظهر على شاشته بالمرحلة **مؤكد**. بعد التجهيز/الشحن تُنقَل إلى **تم الشحن**، وبعد إصدار الفاتورة إلى **الفوترة**.

### الكاشير والدفع الآجل
- كل مندوب هو **الكاشير** على نقطة بيعه (اختفت رسالة «لا يوجد كاشير متوفر»).
- طريقة الدفع الوحيدة على نقاط المناديب هي **آجل** (حساب العميل). اختر العميل ثم ادفع بـ آجل؛ المبلغ يبقى على العميل حتى التحصيل/الفاتورة.

## إعادة تطبيق الإعداد

```bash
cp .env.example .env
# املأ ODOO_USERNAME و ODOO_API_KEY
python3 scripts/configure_brodansh_mandoub.py
```

السكربت آمن للإعادة: يفتح الجلسات المعلّقة، ويحدّث المراحل، وينشئ الشاشات الناقصة فقط.

```bash
python3 -m unittest discover -s tests -v
```

## وحدة أودو اختيارية

المجلد `brodansh_mandoub_pos` وحدة Odoo 18 يمكن وضعها في `addons_path` ثم تثبيتها. بعد ذلك من **نقطة البيع → الإعداد → تهيئة جلسات المناديب** يمكن إعادة نفس الضبط من الواجهة.
