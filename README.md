# Brodansh — تنظيم المستندات

المستندات تُرتَّب حسب الكيان، و**تهيئة المستندات** تظهر فقط لمجموعة **إدارة المستندات**.

## المجلدات

| المجلد | المحتوى |
| --- | --- |
| مصنع ذو الجناحين | 1-تراخيص، 2-عناوين، 3-شهادات، 4-ضرائب، 5-مالية |
| ابنتي الصغيرة | 1-السجل التجاري، 2-عناوين |
| الورشة | 1-تراخيص، 2-عقود |
| عمارة الرمال | 1-تراخيص، 2-عناوين، 3-عقود |
| عمارة المصفاة | 1-تراخيص، 2-عناوين، 3-عقود |
| جداول غير معنونة | الجداول بدون اسم، مرقّمة |

كل هذه المجلدات `access_internal = none`: لا تظهر لبقية المستخدمين. تُشارك مع أعضاء مجموعة **إدارة المستندات**.

## التهيئة

قائمة **المستندات → التهيئة** مربوطة بمجموعة **إدارة المستندات** فقط. مديرو المستندات العاديون يرون الملفات المسموح بها دون قائمة الإعدادات.

الأعضاء الافتراضيون: وليد حسن محجوب، سند. أضف أو احذف أعضاء من **الإعدادات → المستخدمون → المجموعات**.

## التطبيق على السيرفر

```bash
python3 scripts/configure_brodansh_documents.py
```

بعد نسخ الوحدة `brodansh_documents` إلى `addons_path`:

**تطبيقات → تحديث قائمة التطبيقات → تثبيت / ترقية «برودانش — تنظيم المستندات وصلاحيات التهيئة»**
