# Brodansh — جلسات المناديب بدون فوترة من نقطة البيع

المندوب **لا يفوتر** من نقطة البيع. التدفق على برودانش:

1. **المندوب** ينشئ طلباً (عرض سعر مسودة) من نقطة البيع
2. **المدير** يؤكد أمر البيع
3. **المخازن** توصّل (صرف المخزون)
4. **الحسابات** تفوتر بعد التسليم

تم ضبط قاعدة **brodansh** على [https://brodansh.de.com.eg](https://brodansh.de.com.eg) لهذه الشركة: مصنع ذو الجناحين للملابس الجاهزة.

## لماذا اختفت شاشة «تم الدفع بنجاح»؟

نقطة البيع القياسية تدفع فوراً وتُصدر **فاتورة ضريبية مبسطة** (ZATCA). هذا ليس المطلوب. لذلك:

- زر **دفع / Payment** على نقاط المناديب يصبح **إنشاء طلب** بعد تثبيت الوحدة
- حتى قبل تثبيت الوحدة: أتمتة على السيرفر تحوّل محاولة الدفع إلى **عرض سعر** وتمنع الفاتورة
- سياسة فوترة الأصناف: **عند التسليم** حتى لا تُنشأ فاتورة قبل توصيل المخازن
- تأكيد أمر البيع لطلبات المناديب مسموح **لمدير المبيعات فقط**

## الاستخدام اليومي

1. المندوب يفتح نقطة بيعه، يختار **العميل**، يضيف الأصناف.
2. يضغط **إنشاء طلب** (أو دفع، قبل تثبيت الوحدة: تظهر رسالة برقم الطلب).
3. يظهر عرض السعر في **المبيعات** بحالة مسودة، مع نشاط للمدير (لؤي / وليد).
4. المدير يؤكد أمر البيع → نشاط للمخازن (سند) للتوصيل.
5. المخازن تكمل سند التسليم **تـــوصـــيل** من مستودع المصنع.
6. الحسابات تنشئ الفاتورة من أمر البيع بعد الكميات المسلّمة.

## شاشة المطبخ — جلسة واحدة لكل المناديب

افتح **نقطة البيع → الطلبات → شاشة تحضير الطعام** ثم **مناديب**. كل طلبات المناديب تظهر في هذه الجلسة الواحدة.

البطاقة تعرض **اسم العميل** ورقم أمر البيع. الضغط عليها يفتح أمر البيع. الأصناف لا تظهر على الشاشة.

كل طلب يظهر بالمراحل:

1. **التأكيد** — الطلب أُنشئ وبانتظار تأكيد المدير
2. **التوصيل** — المدير أكّد، المخازن توصّل
3. **الفوترة** — تم التسليم، الحسابات تفوتر

البطاقة تنتقل تلقائياً مع تأكيد أمر البيع ثم سند التوصيل.

| نقطة البيع | المستخدم |
| --- | --- |
| مندوب — حسام الدين علي عباس | حسام الدين علي عباس |
| مندوب — عبدالمجيد | عبدالمجيــد 111 |
| مندوب — محمد لطفي | محمد لطفي 11 |
| مندوب — محمد مقبل | محمد مقبل |

## إخفاء نقاط البيع والمطبخ أثناء الضبط

حتى ينتهي الضبط، تظهر **نقطة البيع** و**شاشة المطبخ** لوليد فقط:

```bash
python3 scripts/configure_brodansh_mandoub.py --restrict-to-admin
```

بعدها المناديب لا يرون قائمة نقطة البيع ولا روابط المطبخ القديمة (يتم تجديد رموز الشاشات). الجلسات المفتوحة لا تُغلق.

لإرجاع الظهور للمناديب بعد انتهاء الضبط:

```bash
python3 scripts/configure_brodansh_mandoub.py --restore-access
```

## تثبيت زر «إنشاء طلب» على السيرفر

الوحدة `brodansh_mandoub_pos` يجب نسخها إلى `addons_path` ثم:

**تطبيقات → تحديث قائمة التطبيقات → تثبيت / ترقية «برودانش — جلسات المناديب وشاشة المطبخ»**

بعدها أعد تحميل نقطة البيع (Ctrl+Shift+R). الزر يصبح **إنشاء طلب** ولا تُنشأ فاتورة ضريبية من POS.
